# create-ggstack

An interactive CLI to scaffold a pnpm monorepo in the style of T3 Turbo, with support for Vite, Next.js, shadcn/ui, and shared tooling packages.

## Usage

```bash
# pnpm (recommended)
pnpm create ggstack

# npx
npx create-ggstack my-app --pnpm

# pnpm dlx
pnpm dlx create-ggstack my-app
```

## Requirements

- Node.js >= 22
- pnpm (the generated monorepo uses pnpm workspaces)

## What it scaffolds

```
my-app/
├── apps/
│   ├── web/          # optional Vanilla Vite app
│   └── next/         # optional Next.js app
├── packages/
│   └── ui/           # optional shadcn/ui package
├── tooling/
│   ├── oxc/          # lint + format config
│   ├── tailwind/     # shared Tailwind config
│   ├── tsconfig/     # shared TypeScript config
│   ├── prettier/     # optional Prettier stub
│   └── eslint/       # optional ESLint stub
├── package.json
├── pnpm-workspace.yaml
├── turbo.json
└── .gitignore
```

## Options

| Flag | Description |
|------|-------------|
| `--pnpm` | Use pnpm to run official app CLIs (default) |
| `--npm` | Use npm to run official app CLIs |
| `--yarn` | Use yarn to run official app CLIs |
| `--bun` | Use bun to run official app CLIs |
| `-h, --help` | Show help |
| `-v, --version` | Show version |

## Interactive flow

1. Project name
2. Select apps (Vanilla Vite, Next.js)
3. Name each app
4. Select packages (shadcn/ui)
5. Select tooling (Tailwind CSS, Oxc, Prettier, ESLint)
   - Tailwind is auto-selected if shadcn/ui is chosen

## Official app CLIs

Apps are generated by delegating to their official CLIs:

- Vite: `pnpm create vite@latest apps/<name> -- --template vanilla-ts`
- Next.js: `pnpm create next-app@latest apps/<name>`
